# Privacy Policy

_Last updated: 2025-03-01_

## Overview

DiceFrame is an **open-source, self-hosted** application. The DiceFrame project
does not operate any hosted service and does not collect, store, or process
personal data from end users.

## What This Website Collects

The DiceFrame website (`diceframe.com`) is a static informational site hosted on
Cloudflare. It does **not** use cookies, analytics trackers, or any form of user
tracking. Standard HTTP server logs (IP address, User-Agent, timestamp) may be
retained by the hosting provider (Cloudflare) in accordance with
[Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/).

## Self-Hosted Instances

When you deploy DiceFrame on your own server, all data — game saves, character
sheets, API keys, chat logs — stays entirely on your infrastructure. The
DiceFrame project has no access to your instance and does not receive telemetry
or analytics of any kind.

You are solely responsible for the data handling and privacy practices of your
own deployment.

## Third-Party Services

DiceFrame connects to third-party LLM providers (e.g. OpenAI, Anthropic, or
compatible APIs) using API keys you provide. Those connections are made directly
from your server to the provider. Please review the privacy policy of the LLM
provider you choose.

## Contact

If you have questions about this policy, please open an issue at
<https://github.com/diceframe/diceframe/issues>.

## Changes

This policy may be updated from time to time. Changes will be committed to this
repository and the "Last updated" date above will be revised accordingly.
